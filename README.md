# Painel

Estúdio de roteiro para HQs e mangás.

Ferramenta para criar, organizar e desenvolver roteiros de histórias em quadrinhos e mangás.

## Sobre o projeto

O Painel é um estúdio de roteiro focado em histórias em quadrinhos e mangás.  
Ele ajuda a estruturar cenas, diálogos, páginas e o fluxo da história.
